测试按 16、32、64、128、192、256 MiB 逐档尝试。每档使用 GPU buffer，并通过 GPU clear 操作触发写入，再将首尾区域复制回 CPU 校验。完成后释放所有缓冲区。
重要说明

浏览器可能延迟实际物理内存提交；GPU 缓冲区申请成功不等于全部数据都常驻显存。WebGPU 不向网页开放手机可用 GPU 内存总量。本实验只给出当前浏览器/驱动下可申请并操作的容量下限。不要在手机已经发热或内存紧张时运行。
