# 真实 3D 文本条件训练：数据路线

## 当前已实现

- `real-3d-dataset-collector.html`：手机浏览器本地导入 GLB 2.0。
- 读取未压缩 float32 `POSITION` 顶点，归一化模型包围盒。
- 将顶点序列轻量抽样为 256 个三维点。
- 保存文字描述、源文件名、几何统计、归一化点云到 IndexedDB。
- 可导出 JSON 数据集；不上传模型，不调用云端 GPU。

## 数据集选择结论（2026-11）

### Objaverse 1.0

官方介绍约 80 万个带注释 3D 资产，含名称、描述、标签和元数据。整体数据集采用 ODC-By 1.0，但单个资产有独立许可：CC-BY、CC-BY-NC、CC-BY-SA、CC0 等均存在。因此必须逐资产读取许可字段并过滤，不能把整个集合当作无条件商用素材。官方托管资产规模约 8.9 TB，不适合直接整体下载到手机。

- 官方项目页：https://objaverse.allenai.org/objaverse-1.0/
- Hugging Face 数据卡：https://huggingface.co/datasets/allenai/objaverse

### UniG3D

UniG3D 论文项目提供了 Mesh、点云、图像、文本四种表征的数据构建方案，并发布部分 ShapeNet / Objaverse 统计与转换流程。项目说明完整四元组因存储量大未能以统一方式公开，因此它适合作为数据转换方法参考，不应误称为可直接下载的完整训练包。

- 项目页：https://unig3d.github.io/

## 当前采集器的限制

1. 当前只支持 GLB 2.0 中未压缩的 float32 VEC3 POSITION；暂不支持 Draco、Meshopt、外部 buffer URI、复杂节点变换。
2. 当前 256 点是按顶点数组顺序抽样，不是按三角形面积均匀采样；密集区域可能采样偏置。
3. 当前没有姿态/朝向规范化、部件标签、骨骼/蒙皮处理、材质与纹理训练。
4. 文字描述质量由采集者负责。不得把文件名当作准确语义标签。
5. 点云坐标已居中并按最大包围盒边归一化；原始尺度信息仍保存在 bounds / scale 元数据中。

## 下一阶段的正确训练目标

不是继续训练旧的 12 维合成形体 MLP，而是建立独立的文本—点云模型：

- 输入：文本 token / 词向量。
- 目标：真实模型采样得到的归一化点云（初期 256 点，后续提高点数）。
- 网络：小型文本编码器 + 条件点云解码器；优先采用可在 WebGPU 上分批训练的紧凑 MLP / PointNet 风格结构。
- 损失：Chamfer Distance（双向最近邻距离），并逐步增加法线、局部平滑和部件约束。
- 数据划分：按模型资产 ID 划分训练/验证，避免同一资产的近重复版本同时进入两边。
- 输出：点云先用于验证文本—几何学习是否成立，再研究点云到网格重建；不能把点云直接称为高质量可编辑网格。

## 手机端约束

- 数据采集、训练、检查点和推理继续限定在用户手机本地。
- 训练集先从少量、明确许可、描述准确的 GLB 开始；不要让手机下载数 TB 数据。
- 模型训练需要控制点数、batch、隐藏维度和中间缓冲区，按设备 WebGPU 能力动态降档。
- 浏览器 IndexedDB 有容量限制；用户应定期导出数据集和检查点。
- 不宣称一加 Ace 6 能从零训练达到 Tripo 级别。目标是逐阶段验证端侧文本—几何学习，再提高数据和模型规模。

## 已接入的首批自动数据源（2026-11-21）

- **codepawl/pixel-atlas-glb**：Hugging Face 页面列出 6,194 个 GLB 资产，数据卡标注 CC0-1.0，并提供 caption、subject、模型文件路径等字段。自动训练页现将其作为固定优先数据源，通过 Hugging Face Dataset Server 读取前 100 条元数据，逐条要求记录许可为 CC0-1.0、存在 GLB 路径，再按手机端体积限制下载和解析。
- 页面来源：https://huggingface.co/datasets/codepawl/pixel-atlas-glb
- 数据集特点：以像素风/低多边形物件为主，适合先打通“文字描述—真实几何点云”数据管线，不代表覆盖写实人物、复杂装备或通用场景。
- 训练页：`auto-text3d-platform.html`。数据仅在用户手机浏览器运行任务时下载并保存到本机 IndexedDB；没有把数千个模型塞进 Git 仓库，也不会在后台替手机运行训练。
- 重要限制：当前训练器仍为 256 点、固定点序 MSE 的小型网络；同一数据集不同模型的点序不具备语义对应关系，训练效果可能很弱。自动导入打通不等于文生 3D 质量达标。下一步应先验证 Dataset Server 返回字段和 GLB 下载在目标 Android 浏览器上的实际兼容性，再改进均匀表面采样、点云 Chamfer loss 和批量训练。
