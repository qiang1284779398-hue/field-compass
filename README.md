# 幻想三国 · 乱世称雄

一款原创的手机优先文字卡牌策略游戏，以东汉末年为背景。点击卡片经营城池、招募武将、训练士卒、讨伐敌军。

## 运行方式
直接用浏览器打开仓库根目录的 `index.html` 即可游玩。无需安装依赖、无需后端服务。

如需发布为网页：
1. 打开仓库 Settings → Pages。
2. 在 Build and deployment 中选择 Deploy from a branch。
3. 选择 `main` 分支和 `/(root)` 目录并保存。
4. 等待 GitHub Pages 发布完成后，通过仓库的 Pages 地址访问。

存档保存在当前浏览器的 localStorage 中。清理浏览器数据或更换设备不会自动同步存档。

本项目为原创同人风格玩法原型，借鉴三国题材策略游戏的通用机制，不使用原作美术、素材或代码。
