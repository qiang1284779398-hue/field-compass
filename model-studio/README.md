# 墨造 · 文字转 3D 模型工坊

一个面向手机浏览器的中文轻量 3D 角色生成器。当前版本以**程序化低多边形建模**为基础：输入文字后，将人物身份、体型、甲胄颜色、头盔、胡须、披风和武器解析成参数，在浏览器中直接创建真实 Three.js 网格，并支持导出 GLB。

> 重要：当前版本不是神经网络直接生成任意网格的 AI 模型。它生成的是由可编辑基础几何体组合而成的低多边形角色。复杂雕刻、写实贴图、骨骼动画和任意物体 AI 生成属于后续阶段。

## 在线打开

项目位于主游戏仓库的独立子目录：

- 源码：[`model-studio/index.html`](./index.html)
- 如果仓库已启用 GitHub Pages，可尝试打开：`https://qiang1284779398-hue.github.io/game/model-studio/`

如果 Pages 尚未启用，请先到仓库 Settings → Pages，将 Source 设置为 Deploy from a branch，选择 `main` 和 `/(root)`。

## 当前功能

- 手机优先的响应式中文界面
- 刘备、关羽、张飞、赵云、吕布等人物提示词预设
- 从中文描述识别武器、体型、甲胄主色、胡须、头盔、披风
- Three.js 实时 3D 预览，支持旋转、缩放和复位
- 导出标准二进制 GLB 文件
- 导出人物参数 JSON
- 可选 OpenAI 兼容 Chat Completions 接口，用语言模型把复杂文字解析成外观参数
- 不配置 API 时也能使用本地规则生成

## 使用

1. 用手机浏览器打开页面。
2. 点击刘备、关羽、张飞等预设，或自己输入描述。
3. 点击“立即生成”。
4. 拖动模型旋转，双指或滚轮缩放。
5. 点击“导出 GLB 模型”，把文件导入 Blender、Three.js 或支持 glTF/GLB 的游戏引擎。

建议描述格式：

```text
人物身份 + 体型 + 铠甲/衣服颜色 + 头盔/发型 + 胡须 + 披风 + 武器
```

## 可选 AI 参数解析

展开“高级选项”，填写一个支持 OpenAI Chat Completions 格式的 API 地址、模型名和自己的 API Key。

- AI 只负责理解描述并返回结构化外观参数；最终网格仍由本地 Three.js 程序构建。
- 浏览器直接请求第三方 API 可能受 CORS 限制。
- API 使用可能产生费用；ChatGPT 订阅不等于 API 额度。
- Key 只保留在当前页面运行内存中，不写入 localStorage；刷新页面后需要重新输入。
- 不要在公共设备或不可信页面输入 API Key。

## 技术结构

- 单页 HTML + CSS + JavaScript
- Three.js 0.170.0
- OrbitControls：预览旋转和缩放
- GLTFExporter：导出 GLB
- 通过 CDN 加载 Three.js，因此页面运行需要网络连接

## 当前限制

- 目前主要针对 Q 版武将外观组合，不是通用的任意物体建模器。
- 人物由程序化几何体组合，细节和面部表现仍较简化。
- 当前没有骨骼绑定和动画，GLB 是静态模型。
- 武器是独立网格节点，但尚未实现真实手部握持约束和攻击动画。
- 当前模型不是经过拓扑优化的专业角色生产资产。用于正式游戏前，需要 Blender 检查比例、法线、材质、面数和挂点。

## 后续开发路线

1. **角色系统**：更精细的头部、发型、胡须、盔甲分件、体型参数和武器挂点。
2. **动作系统**：Humanoid 骨骼、待机/行走/攻击/受击/死亡动画，武器跟随手骨。
3. **AI 真正生成网格**：增加后端 Provider 接口，连接图像生成和图像转 3D 服务。
4. **游戏导出预设**：统一朝向、原点、比例、材质命名和 GLB 压缩选项。

后续可研究接入开源图像转 3D 模型，例如 Tencent Hunyuan3D-2.1。它的公开模型说明是图像到 3D，形状模型约需 10GB 显存，纹理生成另需约 21GB 显存；这类服务需要有 GPU 的后端，不适合直接在普通手机浏览器里运行。参考：[Hunyuan3D-2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1)。
